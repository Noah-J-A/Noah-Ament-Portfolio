<strong>theCatacombs.jar</strong><br/>
&emsp;-This file contains "Tales from the Catacombs," a game that was made by three other students and me for our Grade 12 computer science class culminating project.<br/>
&emsp;-Everything in the game was designed and built from scratch by the four of us in Java over the span of around three months.<br/>
&emsp;-The game was designed for "arcade machines" in our school cafeteria, meaning that while playing with a keyboard is fully functional, the help screen was designed for arcade machine buttons and does not display the controls for keyboard input.<br/>
&emsp;&emsp;-WASD to move, U to attack/confirm, I to use ability, O to use item, J to switch ability, K to switch item, L to pause<br/>
&emsp;-My largest contributions include:<br/>
&emsp;&emsp;-The level system (randomized floor layouts, wall collision, level progression)<br/>
&emsp;&emsp;-The leaderboard (reading from and writing to an external leaderboard file, formatting the leaderboard screen, accepting new high scores)<br/>
&emsp;&emsp;-Button functionality/UX (switching between screens, leaderboard keyboard functionality, button swell/white outline when hovered)<br/>
&emsp;&emsp;-Enemy variety (Subclasses of enemies with different stats/abilities, enemy scaling, the Bulldog boss fight)
